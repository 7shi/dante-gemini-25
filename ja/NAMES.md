# 固有名詞一覧

`ja/*.md`（各篇の要約）と `ja/*/NN.txt`（訳文）で用いる固有名詞の表記基準。

## 方針

1. **イタリア人・イタリアの地名**はイタリア語読み。
2. **イタリア人以外**は日本語で定着している慣用読み（原語の読みより慣用を優先）。
3. **古典古代・聖書の人名/地名**は日本語の慣用読み。ラテン語人名は古典式（ウァ・ウィ）、典礼文・聖書句の引用は教会式（ヴァ・ヴィ）。ただし「アヴィケンナ」「アヴェロエス」など定着した綴りは例外。
4. **君主・教皇の序数**は算用数字（例: ボニファティウス8世）。
5. 要約 `*.md` と訳文 `*/NN.txt` で表記を一致させる。
